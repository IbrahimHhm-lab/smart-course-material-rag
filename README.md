# Smart Course Material Question Answering System

## نظام ذكي للإجابة عن أسئلة المحتوى التعليمي باستخدام RAG

مشروع أكاديمي يستخدم تقنيات الذكاء الاصطناعي التوليدي للإجابة عن الأسئلة المتعلقة بالمستندات التعليمية بصيغة PDF.

### Project Overview

The project applies Retrieval-Augmented Generation (RAG) to retrieve relevant educational content and generate answers supported by retrieved context.

### Technologies

- Python
- LangChain
- Groq LLM API
- Text Embeddings
- FAISS Vector Search
- PDF Text Processing
- Google Colab

### System Workflow

PDF → Text Extraction → Text Processing → Embeddings → FAISS → Retrieval → Context Building → Groq → Answer
